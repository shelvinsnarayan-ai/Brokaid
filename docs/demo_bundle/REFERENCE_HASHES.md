# brokAId demo bundle — reference hashes

Two canonical bundles ship in this directory:

| File | Origin | Chain-root hash | Purpose |
|---|---|---|---|
| `ci-alpha.pg.zip` | Pre-R5c-3b PG-generated (archive) | `92e61063c8d225f40bebd2ae794d9d5810bbf9a48d92ba056845c68b6ac1b5d8` | Historical parity pin. Root hash preserved in perpetuity. Not regenerated. |
| `ci-alpha.zip` | R5c-3b Mongo-native (canonical) | See below (identical to PG archive by construction — same event sequence via `_build_event_specs`, R2 byte-identical hash guarantee) | SIRC demo asset. Regenerated by `scripts/build_demo_bundle.py`. |
| `ci-alpha-tampered.zip` | R5c-3b Mongo-native (tampered) | N/A (verify.js exits 1) | Demo asset — proves the offline verifier catches a mid-chain flip. |

## Byte-identical root guarantee

R2 established that the same input event sequence produces the same
`event_hash` on either backend (`canonicalize.jcs` + `event_hash`
helpers are shared between `kernel/trail.py` and
`kernel/trail_mongo.py`). `seed_ci_deterministic_mongo` reuses
`_build_event_specs(slug, tenant_offset)` from
`seeds/ci_deterministic.py` — the seed sequence is shared verbatim
with the PG seeder — so the Mongo-produced `ci-alpha.zip` carries
the same chain-root as the archived PG bundle.

The `seq` field differs between the two bundles (PG: 331..351 due
to a shared BIGSERIAL that had advanced before ci-alpha's insert;
Mongo: per-tenant counter, 1..N). `seq` is not part of `event_hash`
so this asymmetry is cosmetic — the R5b-1b Scene 7 pin already
exercises byte-identical chain-subset equality across backends.

## Regeneration

```
python scripts/build_demo_bundle.py
```

Uses a scratch Mongo database (`DB_NAME=brokaid_demo_bundle`) so the
main store is untouched and per-tenant seq starts fresh on every
run. Two consecutive invocations produce byte-identical zips —
pinned in `backend/tests/test_r5c3_scripts_bundle_mongo.py`.

## Nightly verification

```
python scripts/chain_verify_nightly.py
```

Verifies both the live Mongo ledger and the archived
`ci-alpha.pg.zip` bundle in one pass. Exits non-zero if either
fails. Stdout format:

```
mongo_root=<hash> PASS|FAIL
pg_archive_root=92e61063c8d225f40bebd2ae794d9d5810bbf9a48d92ba056845c68b6ac1b5d8 PASS|FAIL
```
